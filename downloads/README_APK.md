# SmartAttend AI - APK File

## 📱 Download & Install

### APK File Location
```
SmartAttend-v1.0.0-debug.apk
```

### How to Install on Android Phone

#### Method 1: Direct Download (Easiest)
1. Open this link on your Android phone:
   ```
   https://github.com/koremaniteja/face-attendance/releases/download/v1.0.0/SmartAttend-v1.0.0-debug.apk
   ```
2. Tap **Download**
3. When download complete, tap **Install**
4. Tap **Open**
5. ✅ App is ready to use!

#### Method 2: Transfer from Computer
1. Download APK from computer
2. Connect Android phone via USB
3. Transfer file to phone
4. Open file manager on phone
5. Find the APK file
6. Tap to install
7. ✅ Done!

#### Method 3: Using ADB (Advanced)
```bash
adb install SmartAttend-v1.0.0-debug.apk
```

### System Requirements
- **Android Version:** 5.0 (API 21) or higher
- **Storage:** At least 100 MB free space
- **Camera:** Front camera required
- **Internet:** WiFi or mobile data

### First Launch
1. Open SmartAttend AI
2. Click **Sign in**
3. Enter email and password
4. Allow camera permission
5. Start scanning faces!
